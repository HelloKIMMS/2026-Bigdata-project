# 프로젝트 문제정의

## 1. 선택한 데이터

### 데이터 이름

KBO Player Dataset (1982-2025)

### 출처(URL)

https://www.kaggle.com/datasets/netsong/kbo-player-dataset-by-regular-season-1982-2025

### 라이선스

CC0: Public Domain

### 크기

* 약 9,731행 × 39열
* 형식: CSV

### 어떻게 받았나

* Kaggle 사이트에서 CSV 파일 다운로드

---

## 2. 풀고 싶은 문제

### 한 문장으로

KBO 타자 데이터를 활용하여 선수 가치(WAR)에 영향을 미치는 주요 요인을 분석하고, 선수 기록을 기반으로 WAR를 예측하고 싶다.

### 예측/분류 대상(Target)

* Target 변수: WAR (Wins Above Replacement)
* WAR는 야구에서 선수의 종합적인 가치를 나타내는 대표 지표로 사용된다.

---

## 3. 만들 서비스(완성 모습)

### 서비스명

KBO 선수 가치 분석 및 WAR 예측 플랫폼

### 서비스 설명

사용자가 선수 이름을 입력하면 해당 선수의 주요 기록과 가치(WAR)를 시각적으로 분석해주고, 성적 데이터를 입력하면 예상 WAR를 예측해주는 웹 서비스이다.

### 사용자가 입력

* 선수 이름  
  또는  
* 타율(AVG)
* 홈런(HR)
* 타점(RBI)
* 도루(SB)
* OPS
* wRC+
* 나이(Age)

### 서비스가 제공

* 선수 기록 조회
* 선수 가치(WAR) 분석
* OPS와 WAR 관계 시각화
* 홈런과 WAR 관계 시각화
* 예상 WAR 예측
* 유사 선수 추천

### 사용할 기술

* Machine Learning

  * Random Forest Regressor
  * KNN (유사 선수 추천)

* Streamlit

  * 데이터 시각화
  * 대시보드 웹 서비스 구현

---

## 4. 예상 난관 1가지

WAR는 여러 기록이 복합적으로 반영된 지표이므로 단순한 성적만으로 정확하게 예측하기 어려울 수 있다. 이를 해결하기 위해 변수 간 상관관계 분석과 Feature Importance 분석을 수행하여 WAR에 영향을 주는 주요 요인을 파악하고 모델 성능을 개선할 계획이다.
