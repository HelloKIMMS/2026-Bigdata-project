# 프로젝트 문제정의

## 1. 선택한 데이터

이름: KBO Player Dataset (1982-2025)   
출처(URL): https://www.kaggle.com/datasets/netsong/kbo-player-dataset-by-regular-season-1982-2025   
라이선스: CC0: Public Domain  

크기(행, 열): 9,731행, 39열  
형식: csv  

어떻게 받았나(다운로드 / Open API / 크롤링): 다운로드

## 2. 풀고 싶은 문제

한 문장으로: "KBO 역대 타자 기록 데이터로 선수의 FA 시장 예상 가치 등급을 분류 및 예측하고 싶다."

예측/분류 대상(target)이 있나? 있으면 무엇: 있음. 선수의 누적 승리기여도(WAR)를 4구간으로 나누어 정의한 '퍼포먼스 가치 등급(S, A, B, C등급)' (다중 분류 문제)

## 3. 만들 서비스(완성 모습)

사용자가 무엇을 입력하면 → 무엇을 보여주는 앱인가:  
사용자가 웹 화면에서 특정 타자의 스탯(타석 수, 안타, 홈런, 볼넷, 삼진 등)을 슬라이더로 입력하면 → AI 모델이 해당 선수의 예상 FA 가치 등급과 티어별 확률(%)을 분석하여 'AI 스카우팅 리포트' 형태로 실시간 시각화하여 보여주는 대시보드 앱

사용할 기술: ML (Random Forest Classification 등 머신러닝 다중 분류 알고리즘 적용)


## 4. 예상 난관 1가지

데이터(클래스) 불균형(Data Imbalance) 문제    
S등급(프랜차이즈급, WAR 4.5 이상)에 해당하는 뛰어난 시즌 기록은 전체 9,700여 개의 데이터 중 극소수에 불과합니다. 따라서 머신러닝 모델이 압도적으로 많은 다수의 하위 등급(B, C등급) 위주로만 정답을 맞히려고 하는 '편향 학습'이 발생할 수 있습니다. 이를 해결하기 위해 모델 학습 시 클래스 가중치(class_weight)를 조정하거나, 평가지표로 단순 정확도(Accuracy)가 아닌 F1-Score를 꼼꼼히 확인해야 하는 과정이 필요할 것으로 예상됩니다.
